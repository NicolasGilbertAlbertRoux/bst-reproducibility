# Verification record

The checks below were carried out on the private review edition dated 21 November 2026. They use the frozen inputs identified by the repository checksums. Start with `python replay.py integrity`. Each standard run creates its own detailed `report.json` and section logs. Chapter 7 and the claim register describe what can be inferred from these numerical results.
